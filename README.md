# lookahead-limiter

Streaming lookahead limiter for synthetic PCM, with latency compensation
and a per-frame gain trajectory. Python + FastAPI + NumPy/SciPy; all
inputs are local synthetic fixtures — no production accounts or real
business data.

## Layout

```
limiter/
  config.py     # fixed algorithm contract (detection, attack/release, linking)
  contract.py   # sample-block contract validation (typed error categories)
  envelope.py   # pure gain-math primitives
  stream.py     # StreamingLimiter: lookahead ring buffer, latency, flush
  fixtures.py   # deterministic synthetic PCM fixtures (closed-form, no RNG)
  api.py        # FastAPI service (offline + streaming sessions)
  runlog.py     # JSONL run logging (run id, versions, metrics, verdicts)
tests/          # numerical tests + independent reference implementation
scripts/        # make_fixtures.py, offline_demo.py
examples/       # api_demo.py (calls a running server)
fixtures/       # generated .npz + manifest.json (hashes, analytic expectations)
results/        # reviewable run artifacts (test JSONL, demo reports)
docs/REPRODUCE.md
```

## Algorithm contract (`lookahead-limiter/v1`, fixed)

Per input frame `k` with channel vector `x`:

1. **Detection (fixed range):** full-band scalar peak `peak(k) = max_ch |x_ch|`.
2. **Peak mode: SAMPLE peak.** The threshold constrains per-sample peaks
   only. The reconstructed inter-sample (true) peak is *not* bounded —
   `tests/test_true_peak_mode.py` demonstrates this boundary explicitly
   (a sine with true peak > threshold and all sample peaks < threshold
   passes through at unity gain). `peak_mode != "sample"` is rejected.
3. **Channel linking (fixed):** fully linked — one scalar gain, driven by
   the loudest channel, applied to all channels; stereo ratio preserved.
4. **Required gain:** `r(k) = min(1, T / peak(k))`.
5. **Lookahead:** applied gain for output frame `j` smooths
   `R(j) = min(r(j), …, r(j+L))`, `L = lookahead_samples`. The smoother
   sees a peak's required gain `L+1` frames before that frame leaves the
   delay line, and `R` cannot rise until the peak has left — so the gain
   never releases early into a peak (this is what separates a lookahead
   envelope limiter from per-sample hard clipping).
6. **Smoothing (fixed formula):** one-pole
   `g = c·g_prev + (1−c)·R`, `c = attack_coeff` when `R < g_prev` else
   `release_coeff`, `coeff = exp(−1/(τ·fs))`.
7. **Latency:** exactly `L` frames. `process()` emits only ready frames
   (after N inputs, `max(0, N−L)` emitted); `flush()` pushes L silent
   frames so the final L real frames leave the delay line —
   **total emitted == total input, no tail samples dropped**.
8. **Ceiling promise (analytic):** for input peak `A > T`,
   `output_peak ≤ T + (A−T)·attack_coeff^(L+1)`.
   With the defaults (attack 0.5 ms, lookahead 5 ms @ 48 kHz) the
   overshoot term is `(A−T)·4.35e-5`. Measured in `results/`: impulse
   A=2.0 → output peak 0.5000653207009724 vs promised 0.5000653207009725.

Defaults: `threshold=0.5` (linear), `lookahead=5 ms`, `attack=0.5 ms`,
`release=50 ms`, `sample_rate=48000`, `channels=2`.

## Tests

```
python3 -m pytest            # 20 tests
```

Each test asserts concrete numbers and logs its judgment basis (fixture
sha256, config, metrics, thresholds, verdict) as JSONL to
`results/run-*.jsonl`, prefixed with a run id and an environment
fingerprint (Python/NumPy/SciPy/FastAPI versions, git sha).

| Probe | File | Verifies |
|---|---|---|
| short impulse | `tests/test_impulse.py` | L-frame latency observable mid-stream, ceiling promise, gain floor = T/A, gradual closed-form release, flush keeps tail impulse |
| stereo imbalance | `tests/test_stereo_link.py` | one linked gain driven by the loud channel, quiet channel scaled identically, stereo ratio preserved |
| sustained peaks | `tests/test_sustained.py` | steady-state gain = T/A, no mid-sustain release, output = input×gain (not hard clipping) |
| block-boundary burst | `tests/test_block_boundary.py` | chunked ≡ one-shot sample-exactly for two chunkings, ceiling across the boundary |
| true-peak boundary | `tests/test_true_peak_mode.py` | sample-peak semantics proven with 16× scipy resampling |
| contract & API | `tests/test_contract_api.py` | typed error categories (422/404/409), service ≡ library bit-exactly, session streaming ≡ offline |

Reference answers are **not** generated by the tested core alone:
`tests/reference.py` is an independent re-implementation (vectorized
window minimum + explicit smoother loop) checked sample-exactly, and the
ceiling / recovery / steady-state expectations are closed-form formulas
(`math.exp`) evaluated in the tests.

## Service

```
uvicorn limiter.api:app --port 8000
python3 examples/api_demo.py impulse        # end-to-end demo
```

- `GET  /v1/health` — versions + algorithm contract id
- `POST /v1/limit` — one-shot limiting; returns latency-compensated
  `output`, per-frame `gain`, `latency_samples`, and metrics
  (`input_peak`, `output_peak`, `promised_ceiling`, `ceiling_ok`)
- `POST /v1/sessions` → `POST /v1/sessions/{id}/blocks` →
  `POST /v1/sessions/{id}/flush` — true streaming; block responses carry
  `start_index`/`emitted` so the L-frame latency is observable
- Errors: contract violations → 422 `{"error": {"category": …}}`
  (`bad_shape`, `bad_channels`, `bad_dtype`, `non_finite`, `too_large`,
  `bad_config`); unknown session → 404; use-after-flush → 409.
  No abnormal input is collapsed into a 200.

## Fixtures

`python3 scripts/make_fixtures.py` regenerates `fixtures/*.npz` +
`manifest.json` (deterministic; sha256 in the manifest). Tests build the
same signals in memory from `limiter.fixtures`.
