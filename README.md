# merge-check

本地 OCI 风格层归并检查后端。输入为一组已解包的层目录（普通文件、目录、
符号链接与白化标记），输出**按内容计算的最终树**（含每项来源层、内容哈希）
以及分列的失败与不确定诊断。不执行镜像、不创建联合挂载，归并过程对层目录
只读。

## 模块划分

| 模块 | 职责 |
|---|---|
| `src/model.rs` | 运行模型：请求/报告/条目/诊断类型，schema 与引擎版本 |
| `src/paths.rs` | 路径规范化、白化标记解析，禁止逃出隔离根 |
| `src/merge.rs` | 资源算法：overlay 归并引擎（白化、不透明目录、链接校验） |
| `src/store.rs` | 持久状态：每次运行的 JSON 报告，原子写入，run id 防穿越 |
| `src/config.rs` | 配置：TOML + 环境变量覆盖，层根白名单 |
| `src/api.rs` | 诊断接口：Axum HTTP API，错误信封，请求关联 |
| `src/main.rs` | 服务入口：装配配置、日志、HTTP 服务 |

## 归并语义（固定，有测试锚定）

- 层按给定顺序自低向高应用。
- 层内顺序固定：先不透明标记，再白化，再常规条目（父先于子）。
  因此"同层删除后重建"是确定的：白化清掉低层内容，同层新条目生效。
- `.wh.<name>` 删除同层级的 `<name>`（文件或整棵子树）。
- `.wh..wh..opq` 隐藏其目录下所有低层子项；目录本身保留。
- 同名文件/目录互换：目录被非目录替换时整棵子树丢弃，反之亦然；
  目录与目录合并，来源层保留最底层（目录是合并而非替换）。
- 符号链接只记录、不跟随。支持范围：解析后仍在隔离根内的相对链接。
  绝对路径目标、逃出根的目标、超过深度上限（默认 8）的链都是
  **失败**，条目被排除；目标不存在的链接保留但记为**不确定**。

## 快速开始

```bash
cargo test            # 全部单元 + 集成测试（31 个）
cargo run             # 按 config/default.toml 启动，默认 127.0.0.1:8080
```

调用示例见 [docs/API.md](docs/API.md)，完整复现步骤见
[docs/REPRODUCE.md](docs/REPRODUCE.md)。

## 目录

- `fixtures/` — 四个场景的最小数据夹具 + 手写期望树（`expected.json`）
- `tests/` — 独立集成测试（语义对照、API 端到端、只读性断言）
- `evidence/` — 真实运行留存：测试输出、服务日志、正常/异常响应
- `config/default.toml` — 默认配置（绑定地址、状态目录、层根白名单、上限）
