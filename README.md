# Weighted Orthogonal & Similarity Transform Fit (C++20 / CMake / Eigen)

Fits a transform between **already paired** point sets by weighted least
squares:

\[
\min_{R(,s),t}\ \sum_i w_i\,\lVert q_i - sRp_i - t\rVert^2
\]

No correspondence search is performed: column `i` of the source is assumed to
match column `i` of the target. Four modes are provided, with reflection and
rotation-only handled separately:

| Mode token | Rotation | Scale |
|---|---|---|
| `rigid` | proper, `det(R)=+1` | fixed at 1 |
| `rigid-reflect` | orthogonal, `det(R)=±1` | fixed at 1 |
| `similarity` | proper, `det(R)=+1` | fitted uniform `s ≥ 0` |
| `similarity-reflect` | orthogonal, `det(R)=±1` | fitted uniform `s ≥ 0` |

The core is the weighted Kabsch/Procrustes SVD solution with a sign-corrected
orthogonal factor, closed-form scale (`s = tr(DΣ)/‖X‖²F`) and translation from
weighted centroids.

## Modules

- `src/procrustes_contract` — numerical contract: request/result types, mode
  and failure-category enums, input validation.
- `src/procrustes_core` — algorithm kernel: weighted centroids, cross
  covariance, SVD, sign correction, scale/translation, residuals,
  identifiability and non-uniqueness diagnostics.
- `src/procrustes_explain` — structured logger (request id, version, source
  location) and text/JSON result rendering; failures and uncertain conclusions
  are kept in their own sections.
- `src/procrustes_bench` — independent benchmark support: deterministic
  synthetic workloads and a stopwatch (does not use the core to build answers).
- `apps/` — `procrustes_cli`, `datagen` (synthetic fixture generator) and
  `bench_main`.
- `tests/` — independent unit and integration tests, plus an in-tree micro
  test framework (no external test framework).

## Degenerate / identifiability diagnostics

- `total-weight-zero`, `negative-weight`, `empty-input`, `size-mismatch`,
  `dimension-mismatch`, `nan-or-inf` are hard failures with a specific
  `FailureCode`.
- A rank-deficient cross-covariance produces an **uncertainty**
  (`singular-non-unique`), never a silent answer:
  - 2D collinear points: the **proper** rotation is still unique; allowing
    reflections makes the orthogonal map non-unique (two zero-residual answers).
  - 3D collinear points: the proper rotation is non-unique (many rotations map
    one axis onto another).
- Similarity scale is identifiable iff the weighted source cloud is not
  concentrated at its centroid; coincident sources report
  `scale_identifiable=false`.

## First-time setup (native Linux, no containers)

The machine has no system CMake/Eigen, so `scripts/setup_deps.sh` downloads a
prebuilt CMake and the Eigen headers **into `.deps/`** (no root needed):

```sh
./scripts/setup_deps.sh   # ~20s; fetches CMake 3.30.5 and Eigen 3.4.0
source .deps/env.sh
```

## Build, generate sample data, test

```sh
./scripts/build.sh        # configure + build + datagen + ctest
# or step by step:
source .deps/env.sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/apps/datagen --outdir data
ctest --test-dir build --output-on-failure
```

## Run

```sh
# human-readable
./build/apps/procrustes_cli --csv data/rigid2d_exact.csv --mode rigid \
    --request-id my-run

# machine-readable
./build/apps/procrustes_cli --csv data/similarity3d_exact.csv \
    --mode similarity --format json
```

CSV layout (one paired row; dimension inferred, `2d+1` columns):

```
p_1,p_2[,p_3],q_1,q_2[,q_3],weight
```

Run `./scripts/bench.sh` for the synthetic micro-benchmark. See
`docs/DESIGN.md` for the math and `docs/VERIFICATION.md` for the recorded test
commands and results.

## Sample fixtures (`data/`, regenerated by `datagen`)

- `rigid2d_exact.csv` — hand-built 90° rigid transform.
- `similarity3d_exact.csv` — 120° rotation, scale 2, translation.
- `reflection2d_exact.csv` — pure reflection (det −1) plus translation.
- `collinear2d_reflect.csv` — collinear 2D; multiple orthogonal solutions.
- `collinear3d_proper.csv` — collinear 3D; non-unique proper rotation.
- `weighted_noisy2d.csv` — explicitly constructed weighted-zero-mean noise.
- `coincident_source2d.csv` — scale-unidentifiable similarity case.

Each fixture ships with a `*.truth.txt` ledger of the hand-selected generating
transform (a fixture specification, never solver output).
