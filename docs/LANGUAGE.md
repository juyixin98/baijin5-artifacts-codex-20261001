# RL — 受限语言参考

RL 是本项目自带的小型强类型语言，用于在没有任何生产系统参与的情况下，
可重复地演示“公开接口指纹 + 失效传播”。语法为 Go 风格的一个严格子集。

## 词法与模块

- 一个 `*.rl` 文件声明一个模块：`package <名字>`。
- 通过 `import <模块名>` 引入同一构建中的其它本地模块；导入必须位于声明之前。
- 跨模块引用使用限定符 `模块::符号`（双冒号），例如 `core::Offset`。
- 标识符首字母大写表示导出（public），小写表示私有（private），规则与 Go 一致。
- 私有符号只能在声明它的模块内使用；跨模块访问私有符号在编译期被拒绝。
- 注释：`// 行注释` 与 `/* 块注释 */`。

## 声明

```text
type Name <primitive-or-local-base>

const Name [类型] = 常量表达式
sensitive const Name 类型 = 字面量      # 敏感常量，指纹/日志中脱敏

fn Name(参数: 类型, ...): 结果类型 { 语句 }
fn Name[T, U](参数: T, ...): T { 语句 } # 泛型函数
```

- 基本类型：`int`（64 位整数）、`str`（字符串）。
- 用户类型是名义类型（nominal），底层必须是基本类型或本模块已声明的类型。
- 常量在编译期折叠为字面量，并在**每个使用点内联**（这是失效语义的关键）。
  常量表达式支持字面量、一元负号、`+ - * /`、字符串拼接，以及对其它常量
  （含跨模块常量）的引用；常量环在编译期报错。
- `sensitive const` 与普通常量语义相同，但任何指纹清单、诊断输出都只显示
  `<redacted>`，不打印字面量。

## 语句与表达式

- 变量：`var x: int = 1`（类型标注使用冒号；初始值可省略，取零值）。
- 返回：`return` 或 `return 表达式`。
- 条件：`if cond { ... } else { ... }`，条件为整数时 0 为假。
- 表达式：整数字面量、字符串字面量、变量引用、函数/泛型调用、一元 `-`、
  二元 `+ - * / == != < <= > >=` 与括号。
- 泛型调用必须显式给出类型实参：`Scale[int](n, base)`。类型实参必须是具体类型
  （基本类型或已声明的具名类型，限定类型写作 `module/Name` 用于内部单态化键，
  源码中仍用普通类型名）。

## 入口

解释器优先在所有模块中查找 `Run`，其次 `Main`/`main`，零参数调用。
`rlverify run --fn Name` 也可调用指定的零参数导出函数。

## 错误类别

编译期错误带有稳定类别（测试与脚本据此断言，而不是只看“调用失败”）：

- `import_missing`：导入的模块不在本次构建中。
- `unknown_symbol`：名字不存在，或跨模块访问了私有符号。
- `unknown_type` / `unknown_module`：类型或模块无法解析。
- `type_mismatch`：赋值、参数、返回值类型不兼容。
- `arity_mismatch`：实参数量不匹配。
- `typearg_count`：泛型类型实参数量错误或非具体。
- `unsupported_operator`：操作在该类型上不被支持。
- `const_cycle` / `const_type_error`：常量环或常量表达式类型错误。

运行期错误带 `division_by_zero`、`type_error`、`arity_mismatch`、
`unknown_function`、`missing_result`、`stack_underflow` 等类别。
