# 受限形式语义说明

本文件精确定义后端的推理语义，供实现核对与测试预言机对照。
内核 `app/kernel` 是该语义的一个直接实现。

## 1. 语法

- 文字 `L ::= A | -A`（强否定），规则体额外允许 `not L`（NAF）。
- 规则：
  - 严格规则 `r: H :- B1,…,Bm`（体中无 NAF），
  - 可撤销规则 `r: H := B1,…,Bm`（体中可有 NAF）。
- 事实是接地的强否定文字，视为无前提的严格公理。
- 优先关系是规则 id 上的一组有向边 `priority(强, 弱)`，必须**无环**。
- 安全性：规则头变量与每个 NAF 文字中的变量，都必须出现在某个正文字中。

## 2. 接地（grounding）

自底向上按可达原子集迭代：从事实出发，用规则体正文字与当前关系做等值连接，
得到全部一致置换并实例化规则头。安全性保证无需枚举全域笛卡尔积。
NAF 文字只随正文字的置换一并实例化，不产生新项。结果是一个有限命题程序。

## 3. 论证（证明树）

一个论证是以接地结论为根的有限树：

- 叶：事实（公理论证，无假设）；
- 内节点：一条接地严格/可撤销规则的应用，子节点是规则体正文字的论证；
- 规则体中的 `not L` 成为该论证的**假设** `L`（默认成立，直到被证成）。

构造方式为自底向上的最小不动点，并要求同一接地规则实例不得在一棵树中
重复出现（无环论证）。该限制不改变可证性：含环证明删环后仍是证明。
正依赖循环在无事实种子时不产生任何论证（这些文字保持未知，而不是假）。

论证按结构签名去重，集合有限，数量受配置上限保护。

## 4. 攻击关系

两类直接攻击，并沿子论证向上传播：

1. **假设攻击（ASSUMPTION / undercut）**：论证 A 证成了论证 B 假设中的 `L`，
   则 A 攻击 B 中引入该假设的子论证，并攻击其全部超论证。
2. **反驳攻击（REBUTTAL）**：A、B 顶层结论互为强否定 `L / -L` 时按优先级定向：
   - 严格（含事实）强于可撤销；
   - 同类按显式无环偏序的传递闭包比较；
   - **不可比较 ⇒ 双向攻击**（不选择任一出现顺序的一方）。

若 X 攻击某子论证 S，则 X 攻击所有以 S 为子树的上层论证（子论证闭包）。

## 5. Grounded 标签

在有限论证框架 `(Args, Attacks)` 上定义特征函数

```
F(S) = { A ∈ Args | 对 A 的每个攻击者 X，
                    存在 D ∈ S 使 (D, X) ∈ Attacks }
```

取**最小不动点**（自空集向上）：

```
G0 = ∅,  G_{i+1} = F(G_i),  G = ⋃ Gi
```

- `A ∈ G`：**accepted**（无争议地成立）；
- `A` 被某个 `G` 中论证攻击：**rejected**；
- 其余：**undecided**。

注意特征函数查的是攻击者 X 的**入边**（谁攻击 X），不是 X 的出边；
这保证标准的恢复（reinstatement）：若 X 被 G 中的 D 击败，被 X 攻击的
论证可以重新成立。

### 接地文字的状态

对查询文字 `Q`，汇总其全部论证：

- 存在 accepted 论证 ⇒ `accepted / ACCEPTED_GROUNDED`；
- 否则 `-Q` 存在 accepted 论证 ⇒ `rejected / REJECTED_OPPOSITE_GROUNDED`；
- 否则若有论证：
  - 卷入相反结论的双向攻击 ⇒ `undecided / PENDING_MUTUAL_CONFLICT`；
  - 否则（依赖的 NAF 假设存在未决争议）⇒ `undecided / PENDING_UNRESOLVED_ASSUMPTION`；
  - 全部论证都被 grounded 论证击败 ⇒ `rejected / REJECTED_ALL_CHAINS_ATTACKED`；
- 没有任何论证 ⇒ `no_evidence / NO_EVIDENCE_AT_ALL`（**未知，不是假**）。

## 6. 四个验收现象的语义解释

| 现象 | 判定 |
|------|------|
| 鸟会飞、企鹅更具体 | `r2 > r1` 的单向反驳：`r1` 链 rejected，`r2` 链 accepted |
| 尼克松菱形 | 无优先级 ⇒ 双向反驳 ⇒ 双方都不在 G，也未被 G 攻击 ⇒ undecided |
| 严格矛盾 | 仅用事实+严格规则求闭包，若同时得 `L` 与 `-L`，加载期判 state_conflict |
| `not Wingless` 缺证据 | NAF 假设默认成立；一旦严格证成 `Wingless`，假设攻击使链 rejected |

## 7. 与标准框架的关系

这是基于假设的论证框架（Assumption-Based Argumentation）与 grounded 语义的
受限 Datalog 实例：NAF 文字充当假设，证成假设中的文字是反证攻击；
强否定提供反驳攻击；优先级用于在反驳之间定向。选择 grounded（唯一、
无争议、对规则书写顺序不敏感）正是"冲突保留、不取先出现者"的形式化保证。
