# 统计契约（Statistical Contract）

本文档固定估计目标、模型、折结构、方差公式与边界语义。代码实现与测试均以
本文档为准；测试中的手算字面量与独立 oracle 用来核验实现没有偏离契约。

## 1. 目标与可识别性

- 样本：`(X_i, A_i, Y_i)`，`A_i ∈ {0,1}`，n 行 p 列协变量。
- 估计量：ATE = `E[Y(1) − Y(0)]`（配置 `estimand="ATE"`，默认）；
  另有 ATT = `E[Y(1) − Y(0) | A=1]`（`"ATT"`）。
- 识别假设：一致性、条件可交换性 `{Y(0),Y(1)} ⫫ A | X`、正定性
  `0 < P(A=1|X=e(X)) < 1`。ATE 情形下要求 iid 抽样；聚类情形下独立单元是簇。
- 处理效应在所有合成夹具中为常数 `τ = 0.5`，因此真值已知。

## 2. 干扰模型（nuisance models）

- 倾向：`e(X) = logistic(α0 + α⊤X_std?)`，用带 L2（默认 0）的 IRLS 拟合；
  输出裁剪到开区间 `(1e-12, 1−1e-12)` 以避免除零；显式截断在估计层另做。
- 结果：两个臂各拟合一个 OLS（可选岭），默认对协变量做**仅训练折**标准化
  （常数列 scale 记 1）。截距不惩罚。
- 模型族刻意简单，使“哪个模型正确”在 DGP 层面可精确控制：

  | scenario | 倾向 logit | 结果曲面 μ0 | 正确的模型 |
  |---|---|---|---|
  | `both_correct` | 关于 X 线性 | 关于 X 线性 | 两者 |
  | `ps_only` | 关于 X 线性 | X² + 交互 | 仅倾向 |
  | `outcome_only` | X² + 交互 | 关于 X 线性 | 仅结果 |
  | `both_wrong` | X² + 交互 | X² + 交互 | 都不正确 |

  非线性项是拟合设计中**结构性缺失**的特征，不是噪声大小问题。

## 3. 交叉拟合与折外预测对齐

- K（默认 5）≥ 2；处理分层随机发牌，每折两种处理水平都存在（n 允许时）。
- 折 f 的模型只在 `fold_id != f` 的行上拟合，只预测 `fold_id == f` 的行。
- 返回数组与输入逐行对齐：对任意行 i，`e[i], μ0[i], μ1[i]` 来自未见过 i 的
  模型。分区、值域、有限性、长度均在 `OOFPredictions.assert_alignment` 与
  `_validate_partition` 中断言；独立重拟合审计（容差 1e-8）捕获折编号循环
  错位、行置换等。
- **聚类数据必须按簇分折**：同一簇的所有成员属于同一折，避免同簇行跨
  训练/验证（否则折外预测对簇相关数据不再“干净”）。

## 4. 估计内核

截断：`ẽ = clip(e, lo, hi)`，截断比例 `trimmed_fraction` 显式报告。

### 4.1 ATE — Horvitz–Thompson AIPW（默认）

```
φ_i = μ1_i − μ0_i + A_i (Y_i − μ1_i)/ẽ_i − (1−A_i)(Y_i − μ0_i)/(1−ẽ_i)
τ̂   = n⁻¹ Σ_i φ_i
```

分量对照：g-computation `n⁻¹Σ(μ1−μ0)`；IPW
`n⁻¹Σ[A Y/ẽ − (1−A)Y/(1−ẽ)]`。

### 4.2 ATE — 稳定权重（增广 Hájek，`stabilize_weight=true`）

每臂 `d1 = A/e`，`d0 = (1−A)/(1−e)`：

```
ρ1 = Σ d1(Y−μ1) / Σ d1 ,  m1 = mean(μ1) ;  arm1 = m1 + ρ1
ρ0 类同 ;  τ̂ = arm1 − arm0
影响项 φ1_i = (μ1_i−m1) + (d1_i(Y_i−μ1_i) − ρ1 d1_i) / mean(d1)
得分经平移满足 point == mean(scores)，方差公式无需特判。
```

这是比率（Hájek）估计量，与 4.1 的无偏和（HT）有限样本加权不同；两者在
模型正确时渐近等价。响应 `method` 字段标明所用路径。

### 4.3 ATT

```
num_i = A(μ1−μ0) + A(Y−μ1) − (1−A) e/(1−e) (Y−μ0)
τ̂_ATT = Σ num_i / Σ A,  scores = num_i · n/ΣA（保持 mean(scores)=point）
```

## 5. 双重稳健条件（明确表述，不夸大）

> 当且仅当满足正定性与（簇）独立抽样，并且 **倾向模型正确，或两个结果
> 回归都正确** 时，AIPW 点估计 n^1/2 一致、渐近正态，且下述影响函数方差
> 给出有效标准误。**两个模型都错时，一般有偏，名义 CI 不保证覆盖。**

三分量（IPW / gcomp / AIPW）数值接近只作为诊断提示，不是正确性证据。
`both_wrong` 夹具的存在就是为了让测试和复现脚本能够证伪“任意错设仍正确”。

## 6. 影响函数方差与独立单元

设 `φ_i` 为上述逐行得分，`τ̂ = n⁻¹Σφ_i`：

- iid：`V = s²/n`，`s² = Σ(φ_i−τ̂)²/(n−1)`；CI 用正态 1.95996。
- 聚类：`C_g = Σ_{i∈g} φ_i`，G 个簇：

  ```
  V = G / (n² (G−1)) · Σ_g (C_g − C̄)²,   C̄ = G⁻¹ Σ C_g
  ```

  独立单元数报告为 G；CI 用 t(G−1)；G < 30 时置 `small_cluster_warning`。
  注意：朴素地把 n·m 个成员当独立单元会低估标准误（聚类夹具的测试方向
  即 `se_cluster > se_naive`，且数值与独立 oracle 一致）。

交叉拟合把干扰估计视为固定，这是标准 DML/AIPW 一阶渐近方差；高维/过拟合
干扰下的高阶修正不在本契约内。

## 7. 倾向截断的语义

截断到 `[lo,hi]` 改变了极端权重，目标总体朝重叠区域偏移；因此：
- 截断前后点估计可能不同；
- `trimmed_fraction` 必须报告；
- 关闭截断（`enabled=false`）且存在 0/1 倾向时直接 `computation_failed`，
  不返回无穷权重。

## 8. 确定性与重放

- 分折只依赖 `seed`；同 seed + 同数据必须逐位复现（verify 端容差 1e-10）。
- 事件日志保存 seed、折大小、点估计、SE、CI、三分量、失败类别与细节。
- 独立 oracle（scipy L-BFGS-B 逻辑回归、`lstsq` 结果回归、Python 显式循环
  累加 HT 贡献与 Bessel 方差）与被测内核在固定折上的数值差应 ≤ 1e-6
  （不同浮点求和顺序，不要求位级相同）。

## 9. 明确不做的事

- 不做非二元处理、连续处理、生存/截尾结局、工具变量或纵向数据。
- 不做数据驱动的折数/截断参数选择及其不确定性。
- 不做认证鉴权与限流（本地合成后端）。
- ATT 不报告 gcomp/IPW 对照分量（JSON 中为 `null`），也未做覆盖蒙特卡洛。
